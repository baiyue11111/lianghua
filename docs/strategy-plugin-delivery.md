# 策略与数据入口交付记录

日期：2026-10-04。

## 已实现

策略目录 → 自动参数表单 → 数据预检 → 真实回测 → 存档重读 → 同条件对比已接通。策略是单个Python文件，声明Params、数据需求和目标仓位；系统不维护策略参数名单。当前可执行插件为原市场宽度反转和独立双均线，其它历史存档不等于可执行插件。

数据入口按字段、证券范围、历史长度、频率和价格口径读取。字段不足、预热不足、来源变化或证券池不符时明确拒绝。市值、流通市值和流通股本按登记的列名与单位读取；没有按策略名称分支。策略参数或资金改变后可复用同一原始数据版本。

账户从实际成交、每日净额FIFO持有期和公司行动计算费用、现金股息与股息税。已删除绑定参数的预制账户场景及旧schema输入。送转股需要明确股份交付和税基事实，不从复权因子猜测股数。卖出税款先预留，再计算买入预算。

## 使用

进入工作台“策略研究”的“参数回测”，选择双均线及“真实历史 · 固定10股 · 2023—2025”。编辑资金、日期和策略参数，检查通过后运行基准；改参、再次检查、运行修改参数，即可比较两条曲线。

参数编辑会使旧预检失效；过期响应不能覆盖新结果。同条件比较必须满足相同数据、代码、执行规则、时段和权益观测日期。策略None表示不新增调仓，空目标表示退出；预热不下单。信号使用复权指数，成交和账户估值使用原价。

账户政策明确限定2015-09-09起境内个人普通非限售A股。股息税研究扣款日为卖出日和股息到账日两者较晚日期；未卖出潜在税负单独列示；不声称为券商真实扣款日期或逐笔分币账。佣金为显式研究输入。真实保留样本只有现金分红，送转股路径已通过模块测试，未做真实送转股历史验证。
