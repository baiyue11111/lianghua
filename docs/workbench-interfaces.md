# 量研工作台接口与验收边界

前端通过 `ui-protocol.py` 的前端面使用 `frontend/display` 核心。后端的
`src/workbench/port.py` 实现一个通用模块端口，并只由 `src/protocal.py` 分发。
配置文件选择供应商实现；协议和传输层不判断供应商名字。

| 模块 | 输入 | 输出 | 替换位置 |
|---|---|---|---|
| 前端端口 | 查询、日期范围、来源 ID、审核结论 | 类型化 Promise | App 的端口注入 |
| 后端协议 | `UiRequest` | 运行、任务、快照、证据、审核 | `src/protocal.py` 操作目录 |
| 数据适配器 | codes / start / end / keyword | records / raw / data_as_of / scope | configs/workbench.json 的 adapter |
| 研究适配器 | 运行 ID、offset、limit | 运行详情、逐笔记录、权益、文件哈希 | research.adapter |
| 定时器 | 开关、间隔、日期窗口 | 普通同步任务 | 服务组合处 |
| 快照存储 | 完整已校验响应 | SHA256 快照与当前指针 | Store |

供应商字段转换仅在适配器内完成。前端审核表读取通用字段，不因股票代码添加分支。未知来源直接报错。来源失败不重试、不换源。任务失败保留旧指针，并公开失败状态；这不是用旧数据冒充新数据。

原始响应和查询范围随快照保存。快照按内容哈希校验；人工结论保存到独立记录。哈希证明文件没有改变，不能证明供应商没有错误。公告分页总数变化或重复记录都使任务失败，失败页也留存。

## 本次真实范围

- 29 个本地运行存档。指标全部未验收，不改变原策略。
- 报价：配置的两个指数和一只股票，共 3 条。
- 日线：配置的两只股票，2026-09-25 至 2026-10-03，共 6 条，不复权。
- 公告：2026-09-30 查询，共 75 页、2238 条。不是全历史公告。
- 财报：2026-09-25 至 2026-10-03 查询，共 2 条原文目录。未解析财务数值和报告期。
- 定时器需要服务进程运行；测试后所有定时开关已关闭。用户可在页面按需开启。

## 验证

后端测试含端口替换、审核重读、损坏拒绝、失败指针不变、协议校验、并发拒绝、定时窗口及分页完整性。前端测试覆盖标准请求形状和失败不换通道。TypeScript/Vite 构建通过。

实测前端按钮 → HTTP → 东方财富 → 原始响应 → 快照 → 页面重读。30 秒周期产生新报价快照，之后关闭。审核保存后刷新重读。四种来源真实采集均成功，逐来源快照与证据接口检验通过。

公告消融实验：强制 time 排序时，同一记录在第 12 和 15 页重复，采集被拒绝。只删除排序参数后，来源原生分页完整读取 75 页、2238 条且无重复；不使用去重补洞。期间出现的 HTTP 502 也如实保留失败记录。

## 可查证文件

- `src/protocal.py`：当前操作目录和模块分发的唯一来源。
- workbench-live-check.json：真实 HTTP 验收记录。
- data/workbench：不可变快照、任务、审核与失败原始页。

设计依据：[Ports and Adapters](https://alistair.cockburn.us/hexagonal-architecture/)、[A Philosophy of Software Design](https://web.stanford.edu/~ouster/cgi-bin/book.php)、[OpenAPI](https://spec.openapis.org/oas/latest.html)、[W3C PROV](https://www.w3.org/TR/prov-overview/)。

## 收益基准

配置 `benchmarks` 声明基准名称、代码、币种、价格口径和来源 ID。前端经独立 `benchmarks()` / `benchmark(id,start,end)` 端口读取，不调用供应商。后端 Benchmarks 模块只读取既有快照存储；采集仍使用通用来源适配器和同步任务。没有新增端口或临时 HTML 服务。

当前接入沪深300（BaoStock，人民币价格指数），不含分红再投资。真实采集 2014-01-02 至 2025-12-31 的2919个观测。单运行和多运行图使用共同起点，各自归一为1。基准必须覆盖策略图中的日期；缺失会报错，不向前填充、不换源。原指标不重算；图表采样保留首末日。

本次实测29个运行：13个成功对齐；16个因权益日期缺少对应指数行情而明确拒绝，旧记录含非交易日。13个可对齐运行加基准的共同区间比较通过，共14条线。没有删除异常日期或补值。具体任务、快照和逐运行区间见 `workbench-benchmark-live.json`。纯曲线模块测试覆盖共同起点、缺失日期、不重叠区间及无效初始权益。基准端口测试覆盖契约、无快照与无效日期。
