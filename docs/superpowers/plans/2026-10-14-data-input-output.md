# 输入输出数据整理 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. 实际执行仅由用户指定的 gpt-5.6-luna 完成；主代理写计划、监督和复核。

**Goal:** data/ 只保留 input/ 和 output/；过程日志独立放在 log/；复用已有数据，去重后用现有标准协议完成一次真实增量采集写入。

**Architecture:** 输入是一套行情和基本面逻辑表，查询不复制输入；输出保留回测参数、净值序列和成交。采集过程是日志，不是回测输入。所有业务读写只能经过现有 protocal.py；不得创建旁路、软链接或兼容读取。

**Tech Stack:** 当前 Python、Parquet、JSON、既有 DataBus/DataStore 和 collect 模块，不新增数据库或依赖。

**Spec:** 本会话用户的 input/output/log 划分及最新执行约束。

## Global Constraints

- 禁止修改 src/protocal.py 协议标准、src/storage.py、src/collect/、frontend/，也不得修改供应商适配器或增加替代接口。
- 不重新采集已有行情；测试只请求已确认缺少的股票/指数和交易日期。
- 不自动开启调度，不提交 PR，不合并，不覆盖工作区现有无关修改。
- 首先通过可行性门；不通过则只交付计划与精确阻碍，不执行数据迁移或真实采集。
- 获取数据失败、协议不能按目标写入、同键数据冲突、无法证明原有输入保全，均立即停止并报告，等待用户决定；不自行修复。
- 不能直接凭未被引用删掉独有数据。迁移完成、逐表等价证明、复核通过后才删除冗余旧副本；用户未要求保留额外备份。

## Review Focus

- 同证券/日期相同值应唯一；不同值不能静默覆盖。
- 重述基本面不是普通重复：报告期相同但公布时间/版本不同不能误删。
- 今天尚未收盘或供应商未发布时不能将盘中值冒充完整日线。
- 用户指定不改协议和采集模块，不得用目录映射或包装器绕过。
- 净值回测结果不能混合不同参数；日志不能成为内核运行前置依赖。

### Task 1: 只读可行性门

**Files:** 阅读 src/protocal.py、src/storage.py、src/collect/data.py、src/collect/display.py、src/collect/quotes.py、configs/workbench.json；不改源码。

**Interfaces:** 使用既有 DataBus read/write/query 与 collection 操作，不假设 input/output 已受支持。

- [ ] gpt-5.6-luna 独立核对支持的 kind、实际写入位置、采集参数和可用操作。
- [ ] 核对 input/output 与 log 是否能由现有接口表示，不写入试探文件。
- [ ] 若 kind 仅有 sources/runs/state/validation 或收集固定写 sources/snapshots，记录精确代码行号并停止。不能先把目录搬走导致系统不可用。
- [ ] 主代理复核结论。通过后才允许后续任务；未通过不执行 Task 2–5。

### Task 2: 输入清单和去重

**Files:** data/ 只读扫描；最终目标 data/input/；一次性工作脚本放系统临时目录，审计结果放 log/，不增加永久兼容模块。

**Interfaces:** 通过已验证现有标准数据口访问业务数据；不另建存储实例。

- [ ] 列出每个输入表的字段、单位、股票范围、日期范围、行数、唯一键，以及实际被读取的源文件。
- [ ] 行情键是证券标识/日期/频率；不同价格口径不得混为同一值，正式主表保存原始未复权行情，复权事实单独保存而非覆盖价格。
- [ ] 基本面键包含证券、指标、报告期及公布/修订身份。证券身份、交易日历、公司行动作为必要输入，不丢弃。
- [ ] 完全相同记录合并；任何同键不同值输出冲突并停止，不按最新文件名猜测真值。
- [ ] 核对输入覆盖没有缩小，去重后唯一行集合与原有行集合相等；完整 A 股历史是否已有要实测，不允许宣称小样本等于完整历史。

### Task 3: 迁移和清理

**Files:** data/input/、data/output/、log/；仅在 Task 1 证明可行后执行。允许必要配置数据引用更新，但不得改变协议/采集代码或隐藏新增映射。

- [ ] 输入唯一化，不再保留 history_holdout 的完整重复副本；测试改用标准查询切片（若需要修改禁改模块则停止）。
- [ ] 输出保留策略参数、净值和成交；现有派生指标先验证可复算，才移除冗余存储。独有用户回测不得当作临时测试删除。
- [ ] 日志迁入 log/，记录采集时间、来源、请求范围、成功/失败、写入数量；不复制整份业务数据进日志。
- [ ] 用同一请求比较迁移前后数据和回测经济结果：输入记录、净值、成交、最终现金必须完全一致；仅路径元数据可变化。
- [ ] 删除已证明冗余、可重建且无独有输入的旧 archive/ 和旧目录，记录准确删除范围和不可恢复风险。禁止先删后验证。

### Task 4: 真实增量写入测试

**Interfaces:** 必须从现有后端 send 标准操作进入现有 collection 模块，再经既有数据写入口保存；不直接调用供应商绕过入口。

- [ ] 读取上海时区执行时间与交易日状态，以实际执行日期为准；用户说的今天当前为 2026-10-14，跨日执行不得沿用旧日期。
- [ ] 核对指数和股票已有最大日期及缺口，仅请求缺失区间。指数选配置支持的一个大盘指数，股票选已有数据覆盖中的少量证券，避免新建全市场历史任务。
- [ ] 日线仅在收盘且源已发布后检查；未发布则停止说明，不拿前一日或盘中记录冒充。
- [ ] 通过现有标准操作收集并写入开高低收、成交量、成交额；供应商错误或缺字段则立即报告，不修改模块或 fallback。
- [ ] 用标准协议读回，确认证券/日期正确、数值有限、量额单位明确、没有旧区间被覆盖。
- [ ] 重复提交同一新范围不产生重复行；用调用记录证明原有历史未被重新请求。

### Task 5: 独立验收

- [ ] 代码审查代理确认禁改文件没有新增 diff，且没有旁路和兼容逻辑。
- [ ] 用户可见产物审查代理核对目录仅 input/output、log 清晰，没有额外永久脚本或解释性杂物。
- [ ] 行为验收代理检查下面矩阵；主代理复核证据后才宣布完成。

| 用例 | 预期 |
| --- | --- |
| 相同行情重复两次 | 一条记录，所有值不变 |
| 同键不同收盘价 | 停止并报告冲突，无覆盖 |
| 全量与股票/日期切片查询 | 切片严格等于全量筛选 |
| 基本面修订 | 不误删不同公布时间的事实 |
| 已有日期更新请求 | 不向供应商重采已有历史 |
| 新指数和股票日线 | 标准口写入并读回量额及OHLC |
| 今日尚未发布 | 不造成功结果，不替换日期 |
| 原回测 A/B | 净值、成交、现金完全一致 |
| 获取模块报错 | 停止，报告来源/请求/错误，不修代码 |
| 目录和协议边界 | data/仅input/output，日志在log；无禁改文件改动 |
