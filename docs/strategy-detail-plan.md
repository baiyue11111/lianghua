# 策略详情改造

用户已批准研究结论并要求完整实现。

- 首页从统一策略目录读取插件；没有回测记录也显示。历史存档的已移除插件仍可查看。
- 使用策略标识分组，不按显示名称合并；不截断插件目录。
- 进入详情后按当前插件的参数定义显示表单；不提供策略切换或创建入口。
- 改参生成新回测记录；历史记录保持自己的输入与版本。
- 前端模块先失败测试后实现；实际App经标准ASGI接口验证首页→详情→编辑→预检→A/B→存档。
- 冻结输入沿用 data-port-frozen.json，数据沿用 history_holdout；不改算法、账户或历史输入；因真实卸载缓存缺口，统一插件加载口新增文件存在检查。
- 主agent独立重算目标、现金、公司行动、股息税、净值与指标。此次为既有冻结保留样本的工程复验，不宣称新的未见投资样本。
- 桌面与手机验证后关闭浏览器与ASGI进程，无监听端口；报告保存为永久验收文件。
