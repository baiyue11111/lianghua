# 每日研究与动态策略状态

首页回答四件事：当天完成多少个策略配置的验证、当前仿真启用多少个、当天暂停多少个、当天恢复多少个。

`dynamic_selection.py` 是纯计算模块。输入按交易日排列的独立模拟净收益、历史资格的可知日期、启停参数；输出每天的状态、变化原因、滚动净收益、夏普和回撤。它不取数据、不读配置、不成交、不写文件。暂停期间输入收益仍来自原策略独立模拟账户，而非启用组合的收益。

收盘状态只可用于下一交易日。组合真正的资金曲线必须由执行引擎根据启停目标产生；不能直接拿筛选后收益序列冒充实际组合回测。这部分执行与验收尚未接通。

目前 `configs/dynamic_gate.json` 是未验收研究参数：60个交易日观察窗，启用夏普门槛1、暂停门槛0，连续3次确认，至少启用5个交易日，观察窗回撤15%立即暂停。零波动不产生无限夏普；未取得历史资格、样本不足不启用。以上数值不是优化结果，正式使用前须冻结训练窗、做样本外和启停成本回测。

`research_registry.py` 只管理研究记录。源数据、配置、代码、验证证据、状态输入都有哈希；同一记录重复写入不计新运行，已保存文件禁止改写，文件损坏直接报错。当天完成数按策略标识与配置哈希去重，另显示家族数和实际成功运行数。行情或账本未经验证的结果只计入无效次数。未验收启停规则产生的状态只保存用于研究，不进入启用名单；缺少当天判定的旧状态显示“待更新判断”。

记录接口只接收已验收上游报告；哈希能证明记录未改变，不能替代上游数据与会计正确性验收。当前没有真实合格回测接入，所以首页真实计数为0。

命令入口：

```sh
.venv/bin/python tools/research_daily.py --registry data/research_registry --as-of 2026-09-26
```

登记上游的真实运行报告并回放状态：

```sh
.venv/bin/python tools/research_daily.py --registry data/research_registry --as-of 2026-09-26 --run /absolute/path/run-receipt.json --shadow /absolute/path/shadow-net-returns.csv --policy configs/dynamic_gate.json
```

CSV字段为 `day,net_return`。报告字段由 `ResearchRegistry.record_run` 校验。正式通过的动态规则还必须提供验证证据文件及哈希。协议操作 `lake.researchDaily` 读取持久台账；UI按日期显示，不生成测试示例。
