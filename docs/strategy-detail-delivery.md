# 策略详情改造

本轮范围：将参数回测从首页移到策略详情，首页展示插件目录，已移除插件的历史记录仍可查看。

## 模块边界

- 插件文件定义算法、名称、参数与数据需求。
- 首页请求策略目录和历史运行清单，按策略身份关联记录。无历史记录不妨碍进入详情。
- 详情绑定当前插件，按其参数定义生成表单；资金、日期和数据属于本次运行配置。
- 回测记录保存自己的参数、代码、数据和执行版本，不随当前表单改动。
- 已移除插件只能查看历史记录；重新运行需提供符合接口的插件文件。

后端只读检查确认目录与存档读取相互独立，34份已有存档及详情可读取。进一步发现删除文件后Python导入缓存仍可运行；在统一module_spec入口增加文件存在检查，以失败测试重现后修复，预检和运行均明确拒绝已移除插件。历史读取保持独立。

## 验证范围

使用独立于原反转策略的双均线插件，沿用已冻结20/60与10/60参数、100万元、固定10股、2023预热及2024—2025工程保留时段。冻结参数与数据不随页面改造变化。

这次是既有保留样本复验，不是新的一轮投资样本外收益证明。固定10股含证券选择与存活偏差，不能证明全市场表现。此前未复权的历史收益仍无效。
